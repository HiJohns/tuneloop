## 基础设定

| 参数 | 值 | 说明 |
|------|-----|------|
| 日租金 | ¥100 | tier1: 1-30天 @¥100/天 |
| 租期 | 30天 | 标准租期 |
| 合同租金 | ¥3,000 | 30 × ¥100 |
| 押金 | ¥3,000 | |
| 物流费 | ¥30 | 发货时填写 |
| 首期总额 | ¥6,030 | 租金+押金+物流 |
| 赠点cap | 50% | cap_rate=50，最大可用 ¥1,500 |
| 赠点使用 | ¥1,000 | （有赠点场景）|
| 现金支付 | ¥5,030 | ¥6,030 − ¥1,000赠点（有赠点场景）|
| 逾期日费 | ¥150 | 1.5 × ¥100 |
| 损坏赔偿 | ¥500 | （损坏场景）|

## 退款公式（文档定义）

```
Ra = 实付租金（不含押金、物流费）
Re = 应付租金（实际天数 × 阶梯日租）
De = 押金
Dd = 损坏赔偿
O  = 逾期费（overdue_days × ¥150）

R = Ra + De − Dd − O − Re    （最小为 0）
```

退款分配：赠点超 cap 部分退回 promo_points → 剩余退现金。

### ⚠️ 既有 Bug（TDD 须暴露）

代码中 `totalRentPaid = order.CashPaid + GiftPointsUsed`，但 `CashPaid` **含押金+物流费**，导致 `Ra` 被放大。正确应为 `Ra = CashPaid + GiftPointsUsed − Deposit − ShippingFee`。

## 测例矩阵

### 场景 1：正常租赁，按期归还，无损坏，无赠点

| 阶段 | 金额 |
|------|------|
| 首期付款 | 现金 ¥6,030 |
| 实际租期 | 30天 |
| 应付租金 Re | ¥3,000 |
| 损坏 Dd | ¥0 |
| 逾期 O | ¥0 |
| 退款 R | 3000 + 3000 − 0 − 0 − 3000 = **¥3,000**（退押金） |
| 退款分配 | 现金 ¥3,000 |
| 净支出 | ¥3,030（租金+物流）|

## 状态流转覆盖

| 场景 | 起始状态 | 终止状态 | 经过状态 |
|------|---------|---------|---------|
| 1-8 | reserved → paid → in_lease → returning → completed | completed | 正常链路 |
| 7-9（损坏）| returning → pending_damage_response → deposit_refunding / damage_appealing → completed | completed | 新流程 |
| 12-13 | reserved → cancelled | cancelled | 早期取消 |
| 14-15 | paid → cancelled | cancelled | 已付款取消 |
| 10-11 | in_lease/expired → 续期 → in_lease → returning → completed | completed | 续期链路 |

## 测例验证要点

1. **金额精度**：所有计算保留 2 位小数，不出现浮点误差
2. **退款分配**：赠点退回到 promo_points，现金退到 order_refund_records
3. **幂等性**：同一订单 executeRefund 只执行一次
4. **押金标记**：deposit_refunded 在退款执行后置 true
5. **状态守恒**：每个场景的 付款 = 净支出 + 退款（守恒验证）
6. **CashPaid 语义**：TDD 须暴露 CashPaid 含押金/物流的既有 bug
