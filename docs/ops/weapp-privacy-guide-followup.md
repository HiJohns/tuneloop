# 小程序隐私保护指引 — 下次修改清单（待提交）

> 背景：2026-10-19 已在微信公众平台提交一版「用户隐私保护指引」（含接口用途 5 项）。
> 已提交版本对**功能无影响**（关键 scope 已声明，可解除 `errno 112`），但存在口径不完整，
> 审核通过后需按本清单**再提交一次修正版**。
>
> 提交入口：微信公众平台 → 设置 → 基本设置 → 服务内容声明 → 用户隐私保护指引 → 去完善

## 一、接口用途修正（必改）

| 接口项 | 当前（已提交） | 建议改为 |
|---|---|---|
| 摄像头 | 核验承租人身份 | **用于拍摄维修/物流留档照片、证件照及实人核验录像** |
| 选中的照片或视频信息 | 用于上传维修照片、试奏视频与物流留档影像 | **用于上传维修照片、试奏视频、物流留档影像及证件照** |
| 手机号 | 用于账号注册登录、订单通知与售后联系 | 不变 |
| 麦克风 | 用于实人核验录像时采集声音 | 不变 |
| 剪切板 | 用于复制订单号、物流单号及页面链接 | 不变（代码仅 `setClipboardData` 写入） |

> 依据：摄像头实际用于 24 处拍照场景（发货/收货/维修/定损留档），不止身份核验；
> 证件照/人像采集见 `FaceVerify.jsx`、`IdPhotoUploader`。

## 二、需补充声明的信息类型（必改）

当前指引只有 5 个接口项，缺少以下**业务实际收集**的信息类型，需在「信息类型」勾选并填写用途：

| 信息类型 | 用途建议 | 代码依据 |
|---|---|---|
| 身份证号码 | 用于实名认证与身份核验 | `FaceVerify.jsx`（姓名/身份证号） |
| 地址 | 用于租赁/维修的收寄件与物流配送 | 收货/寄件地址表单 |
| 订单信息 | 用于订单创建、支付与售后展示 | 订单/支付流程 |
| 发票信息 | 用于为用户开具发票 | 发票申请 |
| 发布内容 | 用于服务评价与留言展示 | 评价/留言 |
| 邮箱 | 用于账号注册、登录与通知 | `Register.jsx` 邮箱字段 |

## 三、无需声明（明确不勾）

- 用户信息（微信昵称、头像）：未使用 `getUserProfile/getUserInfo`
- 位置信息：平台层有实现但无页面调用
- 相册（仅写入）：未保存到相册
- 选中的文件、通讯录、日历、蓝牙、车牌号、所关注账号、微信运动、传感器、设备信息、操作日志

## 四、流程

1. 等当前提交版本审核通过（状态「已通过/已发布」）
2. 按本清单修改并重新提交（评审期间旧版持续有效，不影响使用）
3. 通过后杀掉微信重进小程序，首次调用接受隐私授权
4. 回归：创建维修单 → 照片/视频选择器可正常弹出（`errno 112` 消失）
