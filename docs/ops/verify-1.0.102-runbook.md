## 1. 什么叫「表单内常驻提示」（判据，第四组通用）

这次要验的不是「有没有报错」，而是**报错长什么样**。判定方法三步，缺一不可：

| 步骤 | 应看到 | 若不符合 |
|---|---|---|
| ① 提交后看提示位置 | 提示出现在**表单内部**（字段上方/下方、`data-testid="site-form-conflict"` 那个 Alert 区），不是屏幕顶部居中的黑条 | 位置不对 → FAIL（记录是 toast） |
| ② 等 **5 秒以上** | 提示**仍然在**（常驻）；3 秒自动消失的 = toast = FAIL | 消失了 → FAIL |
| ③ 改一个字再提交 / 关闭弹窗重开 | 改字段时提示**消失**；重开弹窗时**不应残留**上一次的旧提示 | 不消失或残留 → FAIL |

> 背景：这组（#2569/#2570/#2571/#2572/#2566）就是把「3 秒 toast」改成「表单内常驻」，所以只要出现 3 秒消失的 toast 就算失败。
