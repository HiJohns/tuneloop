# H5 与微信小程序：可被接受的功能实现差异（Acceptable Platform Differences）

> **强制同步要求**：本文件是 H5（`wx.cadenzayueqi.com`）与微信小程序（weapp）之间「**可被接受的功能实现差异**」的**唯一权威清单**。
> 任何开发/调试/评审中，若发现某处 H5 与 weapp 的实现差异**未被本文件覆盖**，**必须先更新本文件**（新增条目或明确判定为"真分歧"并建收敛 Issue，关联 #2172），**再**继续实现。
> 违反此要求 = 静默引入平台差异，视为缺陷（呼应 AGENTS.md 的「文档先行」与「流程可达性审计」原则）。

## 0. 术语

| 端 | 域名/载体 | 代码库 |
|----|-----------|--------|
| **H5** | `wx.cadenzayueqi.com`（**非微信手机浏览器**，如 Safari/Chrome） | `frontend-mobile`（Vite H5） |
| **weapp** | 微信小程序（微信内） | `frontend-mobile`（Taro weapp） |
| **PC** | `web.cadenzayueqi.com`（桌面管理后台） | `frontend-pc` |

> 一致性范围：**H5 ↔ weapp**（同一 `frontend-mobile` 双端编译）。PC 与移动端功能集不同属**另一维度**的合理差异，不在本清单的强制范围（如涉及需另行评估）。

## 1. 判定口径

- **可被接受差异（本清单）**：由平台机制**必然导致**、且用户可感知**结果等价**（H5↔weapp 行为等价，见 #2172 D6）。
- **真分歧（不在本清单，需收敛）**：同一业务意图两端**结果不等价**（导航目标不同、一端弹窗另一端静默、刷新时机不等价、入口不一致、样式静默失效、控件不渲染等）→ 建收敛 Issue（关联 #2172）。

## 2. 可被接受差异清单

| # | 维度 | H5（非微信手机浏览器） | weapp（小程序） | 判定依据 |
|---|------|------------------------|-----------------|----------|
| A1 | 登录/身份 | OAuth / 账号密码 / 短信（无微信 JSAPI） | `wx.login` 无感登录 + 微信授权手机号/头像 | 平台能力；**登录后的会话/权限语义须等价** |
| A2 | 支付 | **Native 扫码**（后端 `code_url` 生成二维码） | **JSAPI**（`Taro.requestPayment` 一键拉起） | 平台能力；支付结果/订单状态语义须等价（#2185） |
| A3 | 导航栏/返回 | 浏览器地址栏；无系统返回 → **页内补 `←`** | 系统导航栏 + 原生 `←` + 手势返回 | 平台 UI；**标题文案与返回目标须一致** |
| A4 | 导航机制 | react-router（无动画） | `switchTab`（tab，无动画）/ `navigateTo`（滑入） | 机制差异；**tab 集合与 active 判定须一致** |
| A5 | 生命周期刷新 | 无 `useDidShow` → `visibilitychange`/路由/轮询 | `useDidShow`（切前台/返回触发） | 机制差异；**"何时刷新"须语义等价** |
| A6 | 扫码 | 无原生 → 手动输入 / 摄像头 | `scanQRCode` 原生 | 平台能力 |
| A7 | 相机/相册 | `<input type=file>` | `chooseImage` 原生 | 平台能力；上传结果语义等价 |
| A8 | 定位 | 浏览器 geolocation（HTTPS+授权） | 微信授权定位 | 平台能力 |
| A9 | 分享/传播 | 无原生分享；微信内 JS-SDK 或复制链接 | `onShareAppMessage` 卡片 | 平台能力 |
| A10 | 样式/渲染 | 标准浏览器（伪类/透明度/任意值全支持） | 无伪类/透明度/`backdrop-filter`；`<rich-text>` 图片受限 | 引擎差异；**须遵守 #1831 禁区、#1907 富文本红线** |
| A11 | 入口/深链 | URL（任意渠道可打开） | 小程序码 / 分享卡片 | 载体差异 |
| A12 | 通知 | 无（或短信/公众号模板） | 订阅消息 | 平台能力 |
| A13 | 文件落地 | 下载 / 长按保存 | `saveImageToPhotosAlbum` | 平台能力 |
| A14 | 沉浸式首页 | H5 实现 | weapp 自定义导航 + 胶囊对齐 | 视觉机制不同（#1510）；**数据/导航/交互行为须一致** |
| A15 | 平台层能力分支 | `platform/browser.js` | `platform/index.weapp.js` | 抽象层实现差异（导出须对称） |

## 3. 覆盖判定流程（每次平台差异相关改动）

1. 问：该差异属于 §2 中的哪一条？→ 属则**无需收敛**（引用条目号）。
2. 不属于 §2 且两端**行为等价** → 补登 §2 新条目（含判定依据）。
3. 不属于 §2 且两端**行为不等价** → **真分歧**：在本文件「§4 已知真分歧/收敛中」登记 + 建收敛 Issue（关联 #2172）。
4. 结论写入对应 Issue/PR 说明。
