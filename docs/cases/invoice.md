# INV-01 发票申请（用户，weapp）

## 前置条件
- 已登录；有可申请发票的订单（已完成且未开票）

## 流程
1. 用户在「发票」页选择订单 → 确认页新增**发票信息表单**
2. 表单（**按商户分组填写**——每个分组=一张发票）：
   - **发票类型**：单选「普通发票 / 专用发票」（默认 普通发票）
   - **发票抬头**：文本，必填，≤255 字符
   - **税号**：文本；**普通发票选填、专用发票必填**；宽松校验（去空格后 15/18/20 位字母数字）
3. 提交 `POST /user/invoices` → `{groups:[{tenant_id, order_ids, invoice_type, title, tax_number}]}` → 按分组创建 `invoice_applications`（三字段落库）
4. 校验失败：类型/抬头缺失 → 前端拦截 + 后端 40002

## 关键规则
- **个人抬头（无税号）允许**（普通发票）
- 专用发票 → 税号必填（后端校验）
- 已有 pending 申请的订单不可重复申请（既有规则不变）

## INV-02 商户回复与详情（PC，发票管理）

- 「发票申请详情」Descriptions 增三项：**发票类型 / 抬头 / 税号**
- 商户回复流程不变（reply + invoice_file）
